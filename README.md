# Sonhos Cosmopolitas

Site institucional e menu digital para um restaurante.

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — estilos e layout responsivo
- `assets/js/main.js` — navegação mobile
- `assets/images/` — espaço reservado para imagens locais
